# ⚠️ Unicord Legacy has been sunset.
Due to changes in TLS requirements on Discord's end, plus the very limited app development model of Windows Phone 7 and a general lack of time and devices to test with, Unicord Legacy has been sunset, and no further official support will be provided. Thank you for your interest and support over the past number of years. Please feel free to fork the repository and continue development if you wish.

### Please note, Unicord Legacy **will not function** on Windows Phone 7 or 8 due to TLS requirements, and you will see a bogus 404 Not Found eror as a result if you attempt to use these platforms. There is **nothing I can do about this**.
